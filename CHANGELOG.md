# Events&I – changelog

## 2026-10-30

- [x] **Markdown renderer nits** — Code spans are held aside like links, so nothing in them becomes emphasis; italics need the `*` to hug words and not sit inside a word or number (`2*3*4` stays as typed); link URLs may contain balanced brackets (Wikipedia-style). Three new tests in `tests/markdown.test.mjs`.
- [x] **Polls with a "count me out" line, registrant suggestions and email-reply moderation** — Registrants rank a poll's options on their manage page (most wanted first) and move a line under the ones they would join; the admin page tallies who would join, who would stay at home, first choices and a preference score, with names. Registrants can suggest their own option and rank it at once; the organiser is emailed and replies `yes`, `no` or `use <wording>` (Cloudflare Email Routing → the cron Worker's new `email()` handler, accepted only from an organiser address with a reference signed by `TOKEN_SECRET`), or decides on the admin page; wording that matches an existing option merges the suggestion and keeps everyone's ranking. Migration 0006, `src/polls.ts`, `src/inbound.ts`, new e2e checks and `tests/inbound.test.mjs`. The sent log gains poll totals (no names). Automatic replies (out-of-office) are dropped without a reply or bounce; only a whole-line answer counts; only the headers are read until sender and reference check out, and HTML is read in linear time. Polls are deleted with the 30-day retention. An independent review's findings (From-header display-name spoofing, parallel suggestions beating the caps, ballot races with merges) are fixed, with unit tests in `tests/polls.test.mjs`. Nothing emails registrants; ballots are deleted with the registration.
